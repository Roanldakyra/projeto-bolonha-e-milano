# Bolonha e Milano

Jogo de estratégia econômica medieval desenvolvido em Java 17, no qual o jogador administra uma cidade, controla seus recursos e toma decisões para desenvolver seu território.

## Etapas desenvolvidas

### Etapa 1
- Classe `Main`.
- Classe `Menu`.
- Menu interativo.

### Etapa 2
- Classe `Jogador`.
- Classe `Cidade`.
- Cadastro do jogador e da cidade.
- Exibição do status da cidade.

### Etapa 3
- Sistema de economia.
- Gerenciamento de florins.
- Integração com o mercado.
- Compra e venda de recursos.

### Etapa 4
- Classe `Agricultura`.
- Sistema de colheita.
- Distribuição de alimentos.
- Gerenciamento de grãos e servos.
- Avanço do ano da cidade.

### Etapa 5
- Classe `Governo`.
- Sistema de arrecadação de impostos.
- Definição da taxa de impostos.
- Gerenciamento do nível de justiça.
- Atualização do status da cidade.

### Etapa 6
- Classe `Construcoes`.
- Sistema de recrutamento de soldados.
- Construção de edifícios.
- Gerenciamento da quantidade de soldados.
- Gerenciamento da quantidade de construções.
- Integração das funcionalidades ao menu principal.

## Funcionalidades do jogo

- Iniciar um novo jogo.
- Visualizar o status da cidade.
- Acessar o mercado.
- Comprar e vender grãos e terras.
- Acessar a agricultura.
- Processar colheitas.
- Distribuir alimentos.
- Gerenciar impostos e justiça.
- Recrutar soldados.
- Construir edifícios.
- Sair do jogo.

## Tecnologias utilizadas

- Java 17.
- Programação Orientada a Objetos (POO).
- Visual Studio Code.
- PlantUML para diagramas UML.

## Como executar

1. Instale o Java 17 ou superior.
2. Abra a pasta do projeto no Visual Studio Code.
3. Acesse a pasta `src/bolonhaemilano`.
4. Execute a classe `Main.java`.
5. Utilize o menu apresentado no terminal para jogar.

## Objetivo do projeto

Desenvolver um jogo de estratégia econômica medieval utilizando conceitos de programação orientada a objetos, organização de classes, encapsulamento e gerenciamento de recursos.

O projeto é desenvolvido por etapas, com a implementação gradual de novas funcionalidades e sistemas de administração da cidade.
